# Problem

    People who spend lots of time on the computer eventually want to know fast they can type. Maybe some people want to improve their typing speed. Or maybe some people might want to see how fast they type compared to others. Friends might want to see who in their group can type the fastest, or they just want to have some fun with custom typing tests.

# Initial requriements

    My program will address this problem by:

        -   providing users with a working typing test (R1)
        -   returning a score measured in words per minute (wpm) (R1)
        -   returning a percentage indicating the percentage of people who got score lower than them (R1)
        -   inputting a .txt file in order to create a custom typing test (R2)
        -   increasing the difficulty of the standard typing test (R3)
