# What the program does

This program lets users take a typing test and learn how fast they can type and where they score compared to other people.

# Commands to Run

For windows users:

1. "pip install windows-curses" (RUN ONCE)
2. "python -m unittest discover tests -v" ---> runs tests
3. "winpty python main.py" ---> runs the main program

For mac/linux users:

1. "python3 -m unittest discover tests -v" ---> runs tests
2. "python3 main.py" ---> runs the main program
