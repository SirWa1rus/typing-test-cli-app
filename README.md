# What the program does

This program lets users either take a standard 45-second typing test with three difficulties (easy, medium, hard) or input a .txt file (containing keys found on any standard keyboard) and use that as the typing test.

# Commands to Run

For windows users:

1. "pip install windows-curses" (RUN ONCE)
2. "python -m unittest discover tests -v" ---> runs tests
3. "winpty python main.py" ---> runs the main program

For mac/linux users:

1. "python3 -m unittest discover tests -v" ---> runs tests
2. "python3 main.py" ---> runs the main program
